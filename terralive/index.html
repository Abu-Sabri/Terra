    Mission Brief

    TerraLive was built to prove that a modern, live-updating dashboard does not need frameworks, bundlers or paid API keys. Every number on this page is fetched at runtime from free, public REST APIs (USGS, Open-Meteo and WhereTheISS.at) using the native fetch() method, parsed as JSON, and written into the DOM with plain JavaScript.

    The whole project is only seven files — five HTML pages, one shared stylesheet and one shared script — which makes the full data flow easy to trace, explain and mark.
