02 How a live page works

STEP 1

Ask for the data

One line of JavaScript — fetch(url) — downloads the newest numbers from the API. No server of our own is involved.

STEP 2

Read the JSON

The reply arrives as JSON: a plain text description of objects and lists. response.json() turns it into JavaScript values.

STEP 3

Write it on the page

The values are put into elements that already exist in the HTML, so the browser only repaints the text that changed.
